### Deskripsi Proyek
Aplikasi sederhana ini mendemonstrasikan pemahaman dasar mengenai tata letak (*layouting*) dan kustomisasi antarmuka pengguna (UI) menggunakan framework Flutter. Proyek ini berjalan dengan baik saat di-*build* secara langsung ke perangkat Android fisik.

### Materi yang Diterapkan
- **Widget & Layout Dasar:** Penggunaan `MaterialApp`, `Scaffold`, `Center`, dan `Column` untuk menyusun elemen secara vertikal di tengah layar.
- **Kustomisasi Teks:** Penerapan `TextStyle` untuk memodifikasi ukuran, ketebalan (*bold*), dan warna pada teks.
- **Integrasi Media:** Menampilkan animasi GIF dinamis yang diambil dari internet menggunakan widget `Image.network`.
- **Styling UI:** Mengatur warna latar belakang aplikasi (*background color*) menggunakan format RGB.

### Catatan Progres (*Commit* Harian)
Proyek ini dikerjakan secara bertahap sesuai instruksi tugas:
1. **Inisiasi:** Setup *repository*, pembersihan kode bawaan, dan persiapan *debugging* via USB.
2. **Kustomisasi Teks:** Menerapkan modifikasi dasar pada `Text` widget.
3. **Penambahan Media:** Mengimplementasikan layout `Column` untuk menggabungkan teks dan gambar/GIF dari internet.
